# Stage 2 Glossary

This is a research-derived working vocabulary, not a canonical schema. Definitions deliberately distinguish units and epistemic states that later specifications must not collapse. Source identifiers resolve through the [source register](2026-09-10-stage-02-sources.md). Terms marked **project usage** are explicit design synthesis rather than quotations or universal disciplinary definitions.

| Term | Working meaning and boundary | Basis |
|---|---|---|
| Research question | The answerable evidence need; different from the business or policy action it may inform. | Project usage; Stage 1; S16 |
| Research protocol | A stated intended method and scope against which changes can be explained; not an after-the-fact description presented as a prior commitment. | S04 |
| Systematic review | A review using explicit methods to identify, select, appraise and synthesise evidence for a defined question; not a label earned by report length. | S02, S31 |
| Scoping review | A structured mapping of the character and extent of evidence; it does not automatically warrant effect or practice recommendations. | S08, S10 |
| Purposive sampling | Deliberate selection for the analytical purpose, such as useful conceptual variation; not an undisclosed convenience sample claimed to be exhaustive. | S14 |
| Eligibility | Criteria for admitting evidence to the research, distinct from whether an item is available, credible or supportive. | S07; project distinction |
| Record, report, study | A search record describes an item; a report communicates research; one underlying study can have multiple reports. | S03 |
| Unit of analysis | The entity actually being compared or counted; its definition must precede interpreting aggregate counts. | Project usage; S03, S20 |
| Primary source | Evidence close to the relevant observation or creation; primary status is relative to the question and does not guarantee truth. | S33 |
| Provenance | Origin and relevant transmission or processing context needed to interpret an evidence item. | Project usage; S23, S35 |
| Independence | Whether evidence has a materially distinct originating basis for this claim, not merely a different publisher or URL. | Project usage; Stage 1; S03 |
| Deduplication | Removing duplicate records while retaining meaningful versions and linking shared underlying units. | S07, S03 |
| Triangulation | Comparing complementary evidence or methods; shared inputs can limit the independence gained. | Project usage; M2, M3, M7 comparison |
| Corroboration | Additional support for a proposition; its value depends on directness and independence rather than quantity alone. | Project usage; Stage 1 |
| Critical appraisal | Examination of a source or study's methodological fitness and limitations; different from testing whether a file or citation exists. | S08, S13 |
| Risk of bias | Potential systematic distortion in a study or inference; distinct from random imprecision. | S13 |
| Evidence extraction / charting | Structured capture of relevant source material and context using consistent, tested instructions. | S09 |
| Meta-analysis | Statistical combination of suitably compatible estimates; not a synonym for any cross-source synthesis. | S12 |
| SWiM | Reporting guidance for quantitative intervention-effect synthesis without meta-analysis; not a generic narrative-writing method. | S15 |
| GRADE / CERQual | Method-specific approaches to certainty in effect evidence and confidence in qualitative findings respectively; not universal source rankings. | S13, S14 |
| Contradiction | Claims that cannot both hold under the same definitions and context; apparent disagreement may instead reflect scope or time differences. | Project usage; research-log Q5 |
| Null / negative result | Respectively, a reported absence of detected effect under a stated test, or a result opposing a specified direction/hypothesis. Neither should be equated with missing evidence. | Project usage; statistical distinction; S12, S32 |
| Assumption / inference | A premise accepted for analysis versus a conclusion reasoned from premises and evidence; neither should be labelled a direct observation. | S28 |
| Likelihood / confidence | Assessment of an event's probability versus strength of the basis for that assessment. | S28 |
| Key Intelligence Topic | A prioritised intelligence need connected to decisions, early warning or relevant actors. | S16 |
| Patent family | Related patent records requiring an explicit family definition for meaningful counting. | S20 |
| Horizon signal | An observed indication of possible change whose relevance, time horizon and evidence remain inspectable. | S22 |
| Preservation / verification | Maintaining an evidence item's integrity and history versus checking what its content and context establish. | S23 |
| Verification / validation | Checking an analysis is implemented correctly versus checking it is appropriate for its intended use. This is AQuA's analytical-assurance usage. | S30 |
| Decision-ready | Adequately supported for the stated use, with material uncertainty, alternatives and limits visible; not an instruction to make the decision. | Project usage; Stage 1; research-log Q7 |
| Correction / refresh | Repair of a defective finding versus reconsideration after changed evidence or context; one operation can trigger the other. | Project usage; S11, S27 |
| Research gap / access gap | Missing relevant knowledge versus an identified source or record that has not been accessed; neither justifies inventing its contents. | Project usage; S36 |

Terms shared across disciplines retain their local meaning. In particular, archival primary evidence is not identical to market-research primary data collection; independent review is not the same as independent evidence; and a preserved source is not necessarily an authenticated observation.
