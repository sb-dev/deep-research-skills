# L5-02 — Watershed system for production

[All research examples](../../README.md#learn-by-researching)

## Problem

Hand scientific mechanisms to game, world and narrative production without treating simulation as empirical proof.

## Exact prompt

Run this prompt in a consumer project with the skill selection it names.

```text
Use installed deep-research and research-evaluate with no Extension Pack. Research a watershed system to inform a fictional world, a game simulation and narrative production. Use original public scientific material from USGS, NOAA and relevant peer-reviewed sources, not generated game lore as evidence. Split the programme into water balance/physical processes, observation and data limits, land-use/human-system interactions, and plausible scenario variation. Preserve units, spatial/temporal scales, assumptions and the distinction between empirical, modelled and hypothetical mechanisms. Inspect decisive diagrams and tables in their original representation.

Deliver separate evidence handoffs to game, world/environment and narrative owners: supported mechanisms, adaptable abstractions, unknowns and tests needed before transferring simulation findings back to real-world claims. Do not implement a simulation or provide site-specific engineering/flood-safety advice. Demonstrate a bounded follow-up and revision that preserves unaffected findings. Future emergent simulation behaviour is a hypothesis to investigate, not empirical proof.

Allow 30 searches and 96 source reads/actions across the programme, reserving review and handoff effort. No additional paid services, purchases or external contact. Write research/l5-02/research.md, programme-map.md, mechanism-evidence-map.md, handoff-game.md, handoff-world.md, handoff-narrative.md, change-record.md and evaluation/audit.md beneath research/l5-02/. Preserve exact original locators, source periods, uncertainty, fixed-input audits and historical revisions. Return actual paths, findings and unresolved scientific/production decisions without claiming a real-world experiment was conducted.
```

Review the actual source access, evidence and claim support, temporal scope, uncertainty, resource bounds and preservation required by the prompt. Distinguish producer self-checks from fixed-input independent evaluation. A passing structural check does not establish research quality.
